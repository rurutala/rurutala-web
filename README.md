# rurutala.net ポートフォリオサイト

環境
React + Vite 

NoSQL Firebase Cloud Firestore

## おすすめ順の編集

`npm run recommendations` でローカルサーバーを起動し、
http://127.0.0.1:4174/manage/recommended を開きます。
ドラッグまたは上下ボタンで並べ替えて保存すると、
`src/data/recommended-order.json` に順番が保存されます。
公開サイトには、このファイルをcommit・pushして反映します。
画面と保存APIはViteの開発サーバーでのみ有効です。
